# Aster v0.12.1 — Windows portable application

Download **Aster-Browser-Agent-0.12.1-Windows-x64.exe** from the release assets. The **Source code** ZIP is for developers and does not contain the ready-to-run application.

## Start in three steps

1. Use a Windows x64 computer with Google Chrome installed and an internet connection.
2. Download the portable EXE and double-click it. No separate backend, Node.js, Python, or `.env` file is needed.
3. Choose OpenRouter, Groq, or Google Gemini, then enter your own API key and exact model ID. Select **Validate and continue**.

Describe a browser task, review its limits, and approve it once. Watch the dedicated Chrome window and use **Downloads** to open or save generated files.

## Included in this build

- Visible browser actions with an agent cursor, click highlights, and a verified in-app preview.
- User-configured providers and models, with API keys encrypted locally using Windows account protection.
- Task-scoped approval, file attachments, and downloadable Excel, Word, PDF, and other supported document formats.
- Bundled Electron/application runtime and the matching Playwright recording runtime. Chrome remains a separate prerequisite.
- A fix for missing video-recording dependencies on computers without a developer's Playwright cache.

## Validation and limitations

The release preparation passed 89 automated tests, the Electron onboarding/production/document journeys, and a smoke test of this portable EXE. The portable test used a fresh profile and an unavailable external browser cache, executed real Chrome navigation, text entry and clicking, and verified a nonempty WebM recording. Model responses in that test were deterministic local mocks, not paid provider calls.

This is a **prototype**, not a guarantee that every website or model will work. Testing was performed on the development Windows PC, not a separate recipient computer. The EXE is **unsigned**, so Windows may show an unknown-publisher warning. Verify the source and checksum before running it; do not disable Windows security protections. Model availability, costs, and account limits depend on your chosen provider.

Tasks, page content, file paths, and screenshots for vision models are sent to the selected AI provider. Uploaded file bytes go to the destination website. Browser cookies, recordings, and documents may contain sensitive information; do not share your profile, settings, or task artifacts with the EXE.

The repository and GitHub release downloads are now public. Sharing the portable EXE directly does not include your API key or local user data.
